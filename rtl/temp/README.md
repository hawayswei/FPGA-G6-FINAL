# temp 子系統

| 項目 | 內容 |
|---|---|
| 負責人 | 整合者 |
| 狀態 | 已模擬（`tb_tmp_temp` PASS）；上板測試待做 |
| 模組前綴 | `tmp_` |
| 時脈 | 125 MHz `clk_i`。SCL 約 100 kHz，由計數器產生 |
| 重置 | 同步、低電位有效 `rst_n_i` |

## 功能

每 0.25 秒用 I2C 讀一次 Pmod TMP3（位址 0x48），把溫度分成五個區間（含遲滯），用 RGB LED 顯示顏色，並在溫度過高或過低時發出一次性事件。

## 模組清單

| 檔案 | 模組 | 用途 |
|---|---|---|
| `tmp_tmp3_reader.v` | `tmp_tmp3_reader` | I2C 讀取。`temp_x2_o` 單位 0.5 °C，只在完整且有 ACK 的讀取後更新 |
| `tmp_zone.v` | `tmp_zone` | 區間判斷、遲滯、RGB PWM、`ev_high_o`／`ev_low_o` |

## 對外介面

| 埠名 | 方向 | 位寬 | 說明 |
|---|---|---|---|
| `scl_o` | 輸出 | 1 | I2C 時脈 |
| `sda_low_o` / `sda_i` | 輸出 / 輸入 | 1 | SDA 開汲極：頂層在 `sda_low_o = 1` 時把腳位拉低，否則放開 |
| `temp_x2_o` | 輸出 | 9（signed） | 溫度 × 2 |
| `valid_o` | 輸出 | 1 | 感測器有回應 |
| `zone_o` | 輸出 | 3 | 0 紫、1 藍、2 綠、3 橘、4 紅 |
| `ev_high_o` `ev_low_o` | 輸出 | 各 1 | 進入偏高、偏低區間時的脈衝 |

## 需要的腳位

Pmod B：SCL = T11（第 3 腳）、SDA = T10（第 4 腳），見 `constr/tmp3.xdc`。

## 已知問題 / 待辦

- 區間邊界是暫定值。TMP3 量到的是體表溫度，會比核心體溫低，邊界要實測後調整。
- I2C 讀取邏輯改寫自 Lab 3 的自寫版本，該版本只通過模擬。
