# constr/

腳位與時序約束（`.xdc`）。**只有整合者編輯這個資料夾。**

- `board_pynqz2.xdc`：板上基本資源（125 MHz 時脈、按鈕、LED），腳位來自課程提供的 `PYNQ-Z2 v1.0.xdc`。
- 各子系統的腳位各自一個檔：`camera.xdc`、`hdmi.xdc`、`servo.xdc`、`bt.xdc`……
  這樣多人同時需要新增腳位時，不會改到同一個檔案。
- 埠名必須與 `rtl/top/pet_top.v` 的埠名一致（`_i` / `_o` 後綴）。

需要新增腳位時，把「子系統、信號名稱、想接的板上腳位」告訴整合者。若腳位與 Pmod、Arduino、樹莓派排針共用，課程 xdc 中有幾組腳位重複（例如 Pmod A 與樹莓派排針），不要同時使用。
