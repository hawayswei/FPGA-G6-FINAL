# docs/

| 位置 | 內容 | 給誰看 |
|---|---|---|
| `spec/` | 課程的題目、評分、採購、影片與報告規定（txt） | 大家 |
| `manual/` | 操作手冊。`00-maintainer-primer.md` 給整合者；組員用的圖文 SOP 待第一次完整演練後補上 | 人 |
| `templates/` | 模板，例如子系統 README 模板 | 大家 |
| `AI_RULES.md` | 貼給聊天 AI 的專案規則（英文） | 人貼給 AI |
| `HANDOFF.md` | 給 Claude Code 的建置規格（英文），完成設定後可保留作紀錄 | AI |

提案、書面報告等文件的協作編輯用 Google Docs 或 Claude Docs；定稿的 PDF 可放 `proposal/`、`report/` 子資料夾。影片放 Google Drive，不放這裡。
